# NSR Canvasser Ramp — Master Tracking Sheet & Dashboard

Tracking system for New Standard Restoration's 45-day canvasser ramp cohorts:

1. **Master Tracking Sheet** — a single Google Sheet with 6 tabs (cohort
   overview, daily tracking, weekly summary, phase gates, ROI projection,
   settings), generated by an Apps Script.
2. **HTML Dashboard** — a single-page web app that reads the sheet through the
   Google Sheets API and displays cohort metrics, phase gates, the 45-day
   timeline, and ROI projections.

```
sheet/
  nsr-master-tracking-sheet.gs   Apps Script that builds the 6-tab sheet
dashboard/
  index.html                     Single-page dashboard (vanilla JS + Chart.js)
  config.example.js              Copy to config.js and fill in Sheet ID + API key
  css/styles.css                 NSR-branded styles, responsive + print-friendly
  js/app.js                      Main controller (tabs, tables, refresh)
  js/sheets-api.js               Google Sheets API fetch + parsing
  js/charts.js                   Chart.js charts (trend, bars, gauge, ROI)
  js/demo-data.js                Built-in sample data (demo mode fallback)
  nsr-logo.svg                   NSR logo placeholder — replace with the real logo
```

## 1. Create the Master Tracking Sheet

1. Go to [script.google.com](https://script.google.com) → **New project**.
2. Paste the contents of `sheet/nsr-master-tracking-sheet.gs` into `Code.gs`.
3. Adjust the `CFG` block at the top (cohort name, start date, canvasser
   names) if needed, then run **`buildMasterTrackingSheet`** and authorize it.
4. Open the execution log — it prints the new spreadsheet's **URL and Sheet ID**.
5. Share the spreadsheet: **Anyone with the link → Viewer** (required for the
   dashboard's API-key access).

The script builds all six tabs with live formulas (conversion %, cumulative
totals, red flags, weekly rollups, gate pass/fail, ROI model) and seeds a few
days of sample data so everything can be verified immediately. PMs only enter
four things daily on the **Canvasser Daily Tracking** tab: doors, leads,
completed inspections, and notes — everything else calculates.

## 2. Get Google Sheets API access

1. In [Google Cloud Console](https://console.cloud.google.com): create a
   project and enable the **Google Sheets API**.
2. Create an **API key**, and restrict it to the Google Sheets API. Once the
   dashboard is hosted, also add an HTTP-referrer restriction for its domain
   (the key is visible in the browser by design; restrictions are what protect it).

## 3. Configure and run the dashboard

```bash
cd dashboard
cp config.example.js config.js   # then edit: sheetId + apiKey
# any static server works:
python3 -m http.server 8080
# → http://localhost:8080
```

Without a `config.js`, the dashboard runs in **demo mode** with built-in sample
data (Cohort #1 at Day 18) and shows a banner — useful for previewing before
the sheet exists. `config.js` is gitignored so the API key never gets committed.

## 4. Deploy

The dashboard is plain static files — no build step.

- **GitHub Pages:** serve the `dashboard/` folder (e.g. Settings → Pages →
  deploy from branch, or copy `dashboard/` into a `gh-pages` branch root).
  Add `config.js` to the deployed copy.
- **Vercel / Netlify:** point the project at `dashboard/` as the output
  directory.
- **Any web server:** upload the `dashboard/` folder.

## Dashboard features

- **Cohort Overview** — status badge (ON TRACK / AT RISK / BEHIND), 45-day
  progress bar with gate markers, phase-distribution cards, next-action box.
- **Metrics Summary** — sortable/filterable per-canvasser table with search and
  click-through weekly detail; cohort averages and health counts; doors/day
  trend chart with 60/day target line; door→inspection bar chart colored
  against the 4% floor; cohort lead-quality gauge (60% target).
- **45-Day Timeline** — week-by-week milestone table with the current day
  highlighted, phase color-coding, gate countdowns, and collapsible upcoming
  events with gate criteria.
- **ROI Projection** — investment / graduates / contribution / ROI cards,
  collapsible assumptions, multi-year payoff chart, and scenario comparison
  (conservative / base / optimistic).
- Manual refresh plus optional 5-minute auto-refresh; responsive layout
  (desktop / tablet / mobile) and a print-friendly view.

## Notes on the numbers

- Weekly earnings = leads × $25 + $500 weekly draw (the 5% GP commission for
  Phase 2+ closes is paid outside this tracker, after job build & collection).
- The per-canvasser training total ($4,700) is recruitment + PM oversight +
  materials; Sales-Manager coordination ($2,000) is a cohort-wide cost and is
  tracked separately, matching the spec's cohort total of $23,500 for 5 heads.
- Scenario ROIs in the sheet are computed from whole-graduate rounding
  (e.g. 30% of 5 → 2 graduates), so they are self-consistent with the model
  rather than copied from the spec's illustrative figures.
